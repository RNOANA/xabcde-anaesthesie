# xABCDE Anästhesie

Digitale intraoperative Antrittskontrolle nach dem xABCDE-Schema mit Rechnern für das Tidalvolumen nach Idealgewicht (unter B) sowie für Blutvolumen, Blutverlust und Hb (unter C).

Konzept aus einer Diplomarbeit im NDS Anästhesiepflege, nicht klinisch validiert. Ersetzt keine fachliche Beurteilung.
Eingaben bleiben im Browser und werden weder übertragen noch gespeichert. Keine Personendaten eingeben.
